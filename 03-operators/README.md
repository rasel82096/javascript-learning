# 03 — Operators

Operators combine, compare, assign, and transform values. This module focuses on what expressions return, not just their syntax.

Run lessons with `node 03-operators/examples/01-arithmetic.js`. Predict each result before running; operators become intuitive through prediction.

## Topics

- Arithmetic and assignment
- Strict vs loose comparison
- Logical short-circuiting
- Unary operators and coercion
- Conditional (ternary) expressions
- `??` and `?.` for missing data
- Bitwise operations (specialised, integer-based)

## Safe defaults

- Use `===` / `!==` unless you explicitly need coercive equality.
- Use `??` for a fallback when `0`, `false`, and `""` are meaningful values.
- Use `?.` only where absence is expected; do not let it hide a required-data bug.
- Parenthesise complex expressions instead of relying on precedence memory.

Read [notes/operators.md](./notes/operators.md) for the reference table and edge cases, then work through `exercises/`.
